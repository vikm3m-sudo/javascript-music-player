# JavaScript Music Player (Spotify Clone)

A Spotify-like music player built using HTML, CSS, and JavaScript.

## Features
- Play / Pause music
- Next & Previous controls
- Progress bar with time update
- Playlist UI
- Responsive design

## Tech Stack
- HTML
- CSS
- JavaScript

## How to Run
Open `spot.html` in your browser.
https://vikm3m-sudo.github.io/javascript-music-player
